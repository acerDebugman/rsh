# rsh M1 Core Implementation Plan

> **For agentic workers:** this is the M1 execution tracker. The normative design is [design/rsh-development-plan.md](../../../design/rsh-development-plan.md); the spec is [docs/superpowers/specs/2026-10-31-rsh-coding-agent-design.md](../specs/2026-10-31-rsh-coding-agent-design.md). Steps use checkbox (`- [ ]`) syntax.

**Goal:** A headless `rsh exec` that talks to DeepSeek, runs a hand-written tool loop, executes the nine tool schemas, and persists a replayable session.

**Architecture:** `llm` owns the wire format and SSE accumulation; `agent` owns the turn/step state machine; `tools` owns one `Tool` impl per tool; `session` owns the JSONL event log. No TUI in M1.

**Tech Stack:** Rust 2024, tokio, reqwest (stream), serde/serde_json, clap, thiserror.

---

## Scope

M1 only. M2 (TUI), M3 (skills/ask_user/compact/resume), M4 (subagents), M5 (e2e) get their own plans after M1 lands. Each task ends in a commit.

## T2 — LLM wire types and SSE accumulator (done)

- [x] `parse_sse_line`: ignore non-data lines, `[DONE]`, malformed JSON error.
- [x] `StreamAccumulator`: text/reasoning deltas, tool-call argument reassembly by index, usage, finish reason.
- [x] 11 tests.

## T3 — Streaming HTTP client

**Files:** create `src/llm/client.rs`; modify `src/llm/mod.rs`, `Cargo.toml`.

- [ ] Add `reqwest` (`json`,`stream`,`rustls-tls`), `tokio` (`full`), `tokio-util` (`rt`), `futures-util`.
- [ ] Define `#[async_trait] pub trait LlmClient { async fn stream_chat(&self, req: ChatRequest, tx: mpsc::Sender<LlmEvent>, cancel: CancellationToken) -> Result<StreamOutcome>; }`.
- [ ] Test first: local `tokio::net::TcpListener` returns an SSE body with one text chunk, one tool-call chunk, usage, `[DONE]`; assert the receiver sees `Text`, `ToolCall`, `Usage` and the outcome has the reassembled call.
- [ ] Test: HTTP 401 returns an error without retry.
- [ ] Implement `OpenAiClient::new(config)`; `POST {base_url}/chat/completions` with bearer key; `bytes_stream` + line buffer; `select!` on cancel.
- [ ] Retry only connect errors/429/5xx, 3 attempts with 250ms/1s/4s backoff.

Verify: `cargo test llm::client`

## T4 — Tool trait and core tools

- [ ] `Tool` trait, `ToolCtx { workspace, permission, cancel }`, `ToolOutput { content, is_error, changed_files }`, `ToolRegistry`.
